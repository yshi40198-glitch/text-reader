# 文字朗读工具（Text Reader）

一个简单、干净、开箱即用的中文文字朗读工具（Windows），离线可用，
断网自动回退本地语音。

> 项目初衷：让文字“听起来”。打开文档就能听，支持倍速、定时关闭、
> 打标记续读，界面极简（黑 + 白）。

---

## ✨ 功能

**电脑版（Windows，解压即用）**
- 打开 PDF / Word（.docx / .doc）/ txt / md / EPUB / HTML 朗读
- 从头朗读 / 从光标朗读 / 朗读选中 / 从标记朗读
- 倍速 0.5x ~ 3x（滑杆 + 快选，阅读中切换平滑生效）
- 音量 0~100%（100% 即满音量）、定时关闭（15/30/60/90 分钟）
- 打标记：听到哪记到哪，随时从标记继续
- AI 网络语音 60+ 声线；断网自动改用本地系统语音继续读完
- 导出音频（AI 语音 MP3 / 本地语音 WAV，失败自动重试）
- 进度条 + 正在朗读段落高亮、系统托盘、桌面快捷方式

## 🚀 快速开始

### 电脑版（推荐直接下载发行版）
去右侧 **Releases** 下载最新压缩包，解压后双击「启动朗读工具.bat」即可，
无需安装 Python。

### 从源码运行（开发者）
```bash
pip install -r requirements.txt
python textreader_app.py
```

---

## 🧩 技术说明

- 界面：Python Tkinter（极简黑白风）
- AI 语音：edge-tts（神经网络语音，需联网）
- 本地兜底：Windows SAPI 系统语音（离线可用）
