# 薇阅 · 文字朗读工具（Weiyue Text Reader）

> 让文字“听起来”——一款温暖、开箱即用的中文文字朗读工具（Windows）。

[English](README.md) | **中文**

**薇阅（Weiyue）** 把 PDF / Word / EPUB / TXT，甚至纸质书页的照片，
变成自然动听的声音。无论是通勤路上的小说、深夜里的工作资料、
练习英语听力的文章，薇阅都能用温暖的声音陪着你。
**免费 · 开源 · 免安装 · 解压即用。**

---

## 🎯 它真的能帮到你

| 场景 | 怎么用 |
|------|--------|
| 📖 **小说 / 电子书听书** | 打开 EPUB / PDF / TXT，点「从头朗读」，闭眼也能“读”完一整本书；1.5x 倍速正好跟上剧情 |
| 🖼️ **纸质书页 / 截图也能读** | 用手机拍一页书或截个图，点「图片识别」，薇阅离线识别文字并立刻朗读 |
| 🎧 **中英文朗读 · 听力学习** | 软件内中英互译，听译文；或逐句跟读练发音 |
| 🎙️ **录音跟读（练口语）** | 听一句 → 自己录一句 → 回放对比，像有个口语陪练 |
| 💼 **商务资料 / 会议材料** | 打开 Word / PDF 简报，2x 倍速快速过；听到重点点「打标记」，随时继续 |
| 🌙 **睡前放松** | 定时关闭 15 / 30 / 60 / 90 分钟，到点自动停，听着听着自然入睡 |

## ✨ n2.6 版本亮点

- 🌐 **文本翻译**：中英互译，长文本自动分段可靠翻译，译文一键朗读

- ⚡ 启动快、打开大文件不卡顿

## ✨ 功能一览

- 打开 PDF / Word（.docx / .doc）/ txt / md / EPUB / HTML 朗读
- 图片识别（PNG / JPG / BMP / WEBP / TIFF）：大图自动缩放、小字自动放大重试
- 文本翻译（中英互译）+ 朗读译文
- 录音跟读：逐句听原音、录音、回放对比
- 从头朗读 / 从光标朗读 / 朗读选中 / 从标记朗读
- 倍速 0.5x ~ 3x 快选，朗读中切换平滑生效
- 音量 0~100%、定时关闭（15 / 30 / 60 / 90 分钟）
- 打标记：听到哪记到哪，随时继续
- 导出音频：AI 语音 MP3 / 本地语音 WAV（失败自动重试）
- 进度条 + 段落高亮、系统托盘、桌面快捷方式
- 所有文本输入处都有右键编辑菜单（剪切/复制/粘贴/删除/全选）

## 🚀 快速开始

### 电脑版（推荐直接下载发行版）
去右侧 **Releases** 下载最新压缩包，解压后双击「启动朗读工具.bat」即可，
无需安装 Python，开箱即用。

### 从源码运行（开发者）
```bash
pip install -r requirements.txt
python textreader_app.py
```

> 提示：图片识别用的是 Windows 自带识别引擎，请在系统设置里确认
> 已安装「中文(简体)」OCR 语言包。

## 🧩 技术说明

- 界面：Python Tkinter（朝阳暖色 · 浮雕质感）
- AI 语音：edge-tts（神经网络语音，需联网，60+ 声线）
- 本地兜底：Windows SAPI 系统语音（离线可用，断网不中断）
- 图片识别：Windows.Media.Ocr（离线，系统自带引擎）
- 录音：sounddevice / numpy
- 文本提取：PyMuPDF / python-docx / HTMLParser
