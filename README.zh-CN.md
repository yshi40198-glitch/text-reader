# 薇阅 · 文字朗读工具（Weiyue Text Reader）

> 让文字“听起来”——一款温暖、开箱即用的中文文字朗读工具（Windows）。

[English](README.md) | **中文**

**薇阅（Weiyue）** 把 PDF / Word / EPUB / MOBI / FB2 / TXT，甚至纸质书页的照片，
变成自然动听的声音。无论是通勤路上的小说、深夜里的工作资料、
练习英语听力的文章，薇阅都能用温暖的声音陪着你。
**免费 · 开源 · 免安装 · 解压即用。**

---

## 一、它能帮你做什么

| 场景 | 怎么用 |
|------|--------|
| 📖 **小说 / 电子书听书** | 打开 EPUB / PDF / TXT / MOBI / FB2，点「从头朗读」，闭眼也能“读”完一整本书；关掉再打开还能接着上次的位置读 |
| 🖼️ **纸质书页 / 截图也能读** | 用手机拍一页书或截个图，点「图片识别」，薇阅离线识别文字并立刻朗读 |
| 🎧 **中英文朗读 · 听力学习** | 软件内中英互译，听译文；或逐句跟读练发音 |
| 🎙️ **录音跟读（练口语）** | 听一句 → 自己录一句 → 回放对比，像有个口语陪练 |
| 💼 **商务资料 / 会议材料** | 打开 Word / PDF 简报，2x 倍速快速过；听到重点点「打标记」，随时继续 |
| 🌙 **睡前放松** | 定时关闭 15 / 30 / 60 / 90 分钟，到点自动停，听着听着自然入睡 |
| ☁️ **云端书库 · 多设备同步** | 有自己服务器（VPS）的用户，可以连接云端书库，电脑、手机读同一批书 |
| 🤖 **对接 AI / 自动化** | 服务器上的 AI 或脚本把书和新闻放进云端书库，薇阅会自动感知新内容并提示朗读 |

## 二、快速开始（3 步上手）

1. 到右侧 **Releases** 下载最新压缩包，解压。
2. 双击文件夹里的「创建桌面快捷方式.bat」，桌面出现金色羽毛图标。
3. 双击图标打开软件，点「打开文件」选一个文档，点「从头朗读」。

> 无需安装 Python，解压即用。

---

## 三、朗读与控制（最常用）

### 三种朗读方式
- **从头朗读**：从文档开头读到结尾。
- **从光标朗读**：先点一下文字（出现竖线），从那里读到结尾。
- **朗读选中**：鼠标划选一段文字再点，只读选中的部分。

右键文字还有快捷菜单：从这里朗读、朗读选中、剪切/复制/粘贴/删除/全选。

### 快捷键
- `Ctrl+O` 打开文件
- `Ctrl+P` 暂停 / 继续
- `Esc` 停止

### 听感调节
- **倍速**：快选 0.5 / 1 / 1.5 / 2 / 3 倍，朗读中切换即时生效。
- **音量**：右侧滑杆 0~100%，夜晚听书调低不吵人。
- **声线**：AI 网络语音（60+ 声线，需联网）；本地系统语音（离线可用）。
- **定时关闭**：15 / 30 / 60 / 90 分钟，到点自动停，适合睡前。

## 四、不怕丢进度

### 自动记住阅读位置
- 读到一半关掉软件，下次打开问「继续读吗？」，点「是」直接接着读。
- 停止、退出时也保存；整本读完后自动清除。

### 打标记
- 听到关键处点「打标记」，之后点「从标记朗读」随时继续。

### 自定义发音词典
- 点工具栏「发音词典」，添加「原词 = 读法」，例如：iPhone = 爱疯。
- 多音字、人名、品牌都能调；朗读、跟读、导出音频全部生效。

## 五、书库

### 本地书库
- 选一个放电子书的文件夹（Calibre 书库、自己的小说文件夹都行）。
- 薇阅自动扫描，按书名、作者、格式列出，双击即读，记住上次的文件夹。
- 支持 EPUB / PDF / Word / TXT / MOBI / FB2 / 网页。
- **删除与回收站**：选中书点「删除本书」→ 书移入回收站；回收站里可以
  「还原」或「彻底删除」，放心管理，不怕误删。

### 云端书库（可连接你自己的 VPS）
- 薇阅默认**不连接任何服务器**，完全本地使用，隐私安全。
- 如果你有自己的服务器（VPS），打开「书库 → 云端书库 → 服务器设置」，
  填入你的服务器地址，即可连接你自己的云端书库：
  - 电脑、手机读同一批书，多设备同步。
  - 服务器上新加了书或新闻，薇阅打开时会提示「云端书库有新内容」。
  - 删除云端书籍需要输入管理员密钥（密钥不写死在代码里，安全）。
- 服务器端组件见仓库 `server/` 目录（书库扫描、语音代理、EPUB 转换等），
  可按需自行部署。软件只连接你自己配置的服务器，不会连接任何第三方。

## 六、学习类功能

### 文本翻译
- 点「翻译」：粘贴文字 → 中英互译，长文本自动分段；译文可朗读、暂停、停止。

### 录音跟读（复读机模式）
- 先打开一篇文章，点「跟读」：听原句（暂停/继续/停止，复读 1/3/5 次或循环）。
- 点「录音」跟着读，再点停止；「回放」对比自己的发音。
- 单次录音上限 3 分钟；录音只在内存中，关窗口即释放。

### 图片识别（OCR）
- 点「图片识别」，选一张图片（书页照片、截图、扫描件）。
- Windows 自带引擎离线识别并立即朗读。

### 智能过滤（自动）
- 朗读时自动跳过页码、页眉页脚，听感更干净。

## 七、导出音频

- 点「导出音频」：AI 语音存 MP3，本地语音存 WAV；长文档自动重试。

---

## 八、早间新闻（可配合 AI 自动推送）

- 软件目录下有个「早间新闻」文件夹：把当天新闻（txt/md）放进去，
  打开软件就提示「要现在听吗？」，点「是」直接朗读。
- 配置了云端服务器后，薇阅还会自动去服务器的「早间新闻」文件夹拉取
  当天的新闻（适合 AI / 自动化脚本每天生成新闻放到服务器）。
- 托盘菜单也有「早间新闻」，随时打开最新一期。

---

## 九、其他功能

- **中英双语界面**：右上角「EN / 中」一键切换。
- **大字号模式**：工具栏「大字号」一键放大正文，老人更清楚。
- **系统托盘**：关闭按钮最小化到托盘（朗读不中断），托盘菜单可暂停/停止/
  早间新闻/退出。
- **读链接**：粘贴新闻/文章网址，抓取正文朗读。
- **配置文件**：软件目录的 `weiyue_config.json` 保存你的设置
  （书库目录、发音词典、服务器地址等），备份它等于备份设置。

## 十一、技术说明

- 界面：Python Tkinter（朝阳暖色 · 浮雕质感）
- AI 语音：edge-tts（神经网络语音，需联网，60+ 声线）
- 本地兜底：Windows SAPI 系统语音（离线可用，断网不中断）
- 图片识别：Windows.Media.Ocr（离线，系统自带引擎）
- 录音：sounddevice / numpy
- 文本提取：PyMuPDF / python-docx / HTMLParser / 内置 MOBI、FB2 解析
- 云端：可配置服务器地址，默认不连接任何服务器
