文字朗读工具 v3.0 · 便携版（朝阳暖色 · 浮雕质感 · AI 神经网络语音 · 中英双语）

不用装 Python，解压即用。朝阳暖色界面：奶油白底、杏橙点缀，
按钮带浮雕立体感，温暖又清爽，疏密有致、一目了然。

【中英双语界面】
- 右上角有「EN / 中」切换按钮：中文界面点「EN」变英文界面，
  英文界面点「中」变回中文界面。
- 切换后所有按钮、菜单、提示立即变为对应语言。
- 英文声线（Aria / Guy / Jenny / Sonia）也在「声线」列表里，
  朗读英文文章时选一个英语声线即可。

【怎么朗读】
1. 双击「启动朗读工具.bat」打开程序（右下角出现金色羽毛托盘图标）。
2. 点「打开文件」选 PDF / Word / txt / EPUB / MOBI / FB2 电子书 / 网页。
3. 三种朗读方式，随心选择：
   - 「从头朗读」：从文档开头一直读到结尾。
   - 「从光标朗读」：先用鼠标在文字里点一下（出现竖线光标），
     再点这个按钮，就从光标位置读到结尾。
   - 「朗读选中」：用鼠标划选一段文字，再点这个按钮，只读选中的部分；
     如果没划选，会自动变成「从光标朗读」。
4. 右键文字还有快捷菜单：可以从光标处开始朗读，或朗读选中内容。

【大字号模式】
- 工具栏右侧有「大字号」按钮，点一下正文立即放大，再点恢复。
- 老人看屏幕更清楚，适合中老年用户。

【书库（本地 + 云端）】
- 点「打开文件」旁边的「书库」按钮，窗口顶部可以切换「本地书库」和「云端书库」。
- 本地书库：选一个存放电子书的文件夹（Calibre 书库、自己建的小说文件夹都可以），
  薇阅自动扫描，按书名、作者、格式列出，双击即读；会记住上次用的文件夹。
- 本地书库删除：选中一本书点「删除本书」，书会移入书库文件夹下的
  「薇阅回收站」子文件夹（不真正删除，随时能找回）。
- 回收站入口：本地书库窗口右下角「回收站」按钮，点开能看到删过的书，
  支持「还原」（放回书库）和「彻底删除」（永久删除，无法恢复）。
- 云端书库：直接列出手机网页版书库里的书（和手机同步），双击即可下载朗读；
  选中一本书后点「删除本书」可从云端删除。云端书库需要联网。
- 云端书库的服务器地址默认不填：点「服务器设置」填你自己的服务器地址
  （例如 https://你的服务器.com），不填就不连接任何服务器。
- 删除云端书籍需要输入删除密钥（只有管理员知道），密钥不写死在软件里；
  手机网页版删除时第一次输入，只保存在你自己的手机浏览器。
- 上架新书只能在服务器文件里操作（把 txt 放进 library 文件夹），软件不能上架。
- 支持 EPUB / PDF / Word / TXT / MOBI / FB2 / 网页等常见格式。

【录音跟读（复读机模式，练口语）】
- 点「跟读」按钮打开跟读面板：先打开一篇文章，面板里会逐句列出原文。
- 听原句：点「听原句」开始，可以「暂停 / 继续 / 停止」，反复听同一句。
- 复读次数：1 次 / 3 次 / 5 次 / 循环，间隔可选 0.5 / 1 / 2 秒，
  跟以前的英语复读机一样，一句能连听好几遍。
- 显示「原句 X 秒」，让你知道原句有多长。
- 录音：点「录音」开始跟着读，再点一次「停止」结束，实时显示已录秒数，
  单次最多 3 分钟；录完显示「录音 X 秒」，点「回放」对比自己的发音。
- 上一句 / 下一句自动连播，练完一句直接进下一句。
- 首次录音请允许使用麦克风。

【图片识别（OCR，扫描图片读文字）】
- 点「图片识别」按钮，选择一张图片（手机拍照的书页、截图、扫描件），
  薇阅自动识别图片里的文字并开始朗读。
- 用 Windows 自带的中文识别引擎，无需联网，识别完立即朗读。
- 适合读纸质书页照片、网页截图、旧扫描文档。

【智能过滤（自动）】
- 朗读时会自动跳过页码、页眉页脚等杂音，让听感更干净。

【倍速（0.5x ~ 3x，真实可感）】
- 直接点「快选」里的 0.5x / 1x / 1.5x / 2x / 3x 切换。
- 切换后立即从当前段落按新速度重新朗读，马上能听出差别。
- 0.5x~2x 用语音合成实现（音调自然）；2x~3x 再叠加播放器加速。

【音量（0% ~ 100%）】
- 界面右侧「音量」滑杆，拖动即时生效，当前百分比会显示在旁边。
- 调低后适合夜晚听书，不吵到别人。

【定时关闭】
- 「定时关闭」下拉可选：15 分钟 / 30 分钟 / 60 分钟 / 90 分钟。
- 到点自动停止朗读，旁边会显示剩余时间倒计时。
- 选「关闭」可随时取消。

【标记位置】
- 听到想停下的地方，点「打标记」记下当前位置（正在读时记当前段落，
  没在读时记鼠标光标位置）。
- 之后点「从标记朗读」，就从标记处继续往下读。
- 标记可以反复打，后打的会覆盖前面的。

【自动记住阅读位置（新）】
- 读到一半关掉软件，下次打开会问「继续读吗？」，点「是」直接从上次
  位置接着读，不用再从头找。
- 停止、退出时也会保存进度；整本读完后自动清除，下次从开头读。

【自定义发音词典（新）】
- 点工具栏「发音词典」，添加「原词 = 读法」条目，例如：
  iPhone = 爱疯、薇阅 = 薇 阅。
- 朗读、跟读、导出音频都会按你的读法来。

【MOBI / FB2 电子书（新）】
- 现在支持 Kindle 的 .mobi / .azw 和 .fb2 电子书，直接打开就能读，
  不用先转成 txt。

【早间新闻提醒（新）】
- 程序目录下有个「早间新闻」文件夹（首次运行自动创建）。
- 把当天的新闻（txt / md）放进去，打开软件就会提示
  「早间新闻已就绪，要现在听吗？」，点「是」直接朗读。
- 托盘菜单也有「早间新闻」，随时打开最新一期。
- 如果配置了云端服务器，薇阅还会自动去服务器「早间新闻」文件夹
 拉取当天的新闻（适合 AI / 自动化脚本每天把新闻放到服务器）。

【云端书库更新提醒（新）】
- 打开软件时自动对比服务器书单，发现有新书（比如 AI 放进书库的）
  会弹窗提示「云端书库有新内容」。
- 云端书库界面右上角有「刷新」按钮，随时手动重新拉取书单。

【朗读过程中】
- 底部进度条显示读到第几段，正在读的段落会高亮并自动滚动。
- 暂停 / 继续 / 停止按钮随时可用。
- 想导出成音频文件：点「导出音频」，AI 语音存 MP3（自动重试，稳定输出），
  本地语音存 WAV。
- 网络中途断开时，AI 语音会自动改用本地语音把剩余内容读完，不中断。

【声线和语音来源】
- 右侧「语音来源」：AI 网络语音（推荐，自然逼真，需联网）/
  本地系统语音（离线）。
- 「声线」下拉可切换 60 多种声音：晓晓（女声）、云希（男声）、
  粤语、台湾腔、东北话、英语等。
- 断网时 AI 语音会自动改用本地语音，不会报错。
- 注意：60 多种声线（AI 网络语音）需要联网才能用；不联网时自动改用
  本地系统语音，声线数量取决于 Windows 自带的语音包（一般就几种）。

【放到桌面用（推荐）】
双击「创建桌面快捷方式.bat」，桌面会出现金色羽毛图标
「文字朗读工具」，以后双击它就能直接打开软件。

【如果出问题】
- 双击「AI语音测试.bat」检查 AI 语音（需联网）。
- 双击「自检.bat」检查所有组件。
- 双击「排错用-带窗口启动.bat」看报错信息。

【注意】
- python 文件夹是自带的，别动。
- .txt 自动识别 UTF-8 / GBK 编码，不乱码。
- .doc（旧版 Word）：本机装了 Word 才能直接读；没装就提示另存为 .docx。
- PDF 若是扫描件/图片（没有文字层），需 OCR，暂不支持。
